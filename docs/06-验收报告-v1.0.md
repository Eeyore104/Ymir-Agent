## 4. C. 核心独立验证（探针与真实演示）

### C1 模型网关真实计量（T02）
`smoke_gateway.py` 真实调用：executor 档（deepseek-chat）16+38 tokens / ¥0.000092 / 1061ms；planner 档（deepseek-reasoner）37+108 tokens / ¥0.001444 / 1388ms。两条均落 `model_calls`；`/usage?scope=global` 端到端核验 calls=2 / tokens=199 / **cost=¥0.001536**（与明细逐项对上）。

### C2 杀进程恢复（T02，真实操作）
并发 10 run 执行中途 `taskkill /F` 杀服务 → 8 个 run 留下 running 猝死现场（阶段残缺各异）→ 重启 lifespan 自动恢复 → **8/8 恢复到 completed**（全走幂等补推进、无重复执行；events 内 `interrupted:true` 标记）。

### C3 Docker 沙箱限额（T03，真实 Docker）
`scripts/verify_docker_sandbox.py` 8 项（探测/CPU·内存限额/exec/超时/内存 OOM/文件/断网/销毁）：python:3.12-slim **8/8 PASS**；`docker/sandbox.Dockerfile` 构建 ymir-sandbox 镜像（26s）→ **8/8 PASS**。过程中硬化：`memswap_limit=memory`（防 swap 逃逸限额）。

### C4 真实四角色全链路（T03，真实 DeepSeek）
单跑 PM（66.6s → PRD v1，¥0.167）→ 全链四角色（173.6s → PRD v2 / design v1 / code v1（15 文件）/ evaluation_report v1；6 次调用 / 78,437 tokens / **¥0.317**）。演示暴露 2 项问题当场修复（smoke_report 注入 QA 下游 / engineer 提示词自包含增强）。

### C5 评测对抗探针（T05，三轮 30/30）
- 双门槛边界：75∧60 → pass；76∧59 → fail；74∧100 → fail ✅
- 权重精确：30/30/20/20，Σ(dim×weight)=77.00 ✅；部分覆盖重归一 / 全零回退等权 ✅
- 证据缺失强制压分：judge 给 5 分但无证据 → 压至 **20.0** ✅
- 单维异常降级：抛异常维 0 分 + 说明，报告不整体失败 ✅
- 组件不可用重归一化：ruff 不可用 → 跳过 lint 后重归一（100，而非 37.5）✅
- 沙箱降级链：provider 抛错 → 降级无沙箱继续（**修复前 FAIL，修复后 PASS**）✅
- 架构冻结常量零漂移：干净=100 / 1 环=85 / 1 超大=95 / 顶层违规=94 / **嵌套违规=94（修复后真实触发）** ✅

### C6 导出 zip 还原性（T05）
多产物导出 → `manifest.json` 完整（current_version / versions / content_hash / 血缘）→ 内容**逐字节还原**；空项目 → 合法空 zip 不崩；不存在 id → 404/1002（非 500）。

### C7 API 契约与错误路径（T05）
`POST/GET /evaluations`、`GET /projects/{id}/evaluations`、`GET /projects/{id}/export` 信封均 `{code:0,data}`；不存在项目 → 404/1002；缺产物 → 400/1001；非法 scope → 400/1001（非 500）；带 run_id 评测触发 `evaluation.completed` 事件。

### C8 驳回回退（T04）
驳回 → feedback 消息入角色上下文 + `attempt+1` 重跑 + 产物 v2 新版本（正常血缘）；实现方式：作废最新 completed StageExecution（置 failed）→ 引擎恢复分支自然重跑，**`engine.py` 零改动**；decide() 内 2s 有界等待容忍竞态。

### C9 e2e 全链路（T05）
`tests/e2e/test_full_pipeline.py`：假响应下四阶段全跑（产物集={prd, design, code, evaluation_report}）→ `run.status=="completed"`；事件链 `run.started(mode=key_node)/run.completed/artifact.created` 完整；四维报告每维带证据链。

### C10 演示库清理安全性（T5-5⑤）
临时拷贝库实测：`--dry-run` 绝不删除；`--yes` 删除 + 级联（runs/artifacts/messages/events/approvals）+ 产物目录清理；**原库 `data/demo_t04.db` md5 前后一致、未被触碰**。
